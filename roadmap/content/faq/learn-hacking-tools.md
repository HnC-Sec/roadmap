Learn the fundamentals first, then pick up tools as you need them. Tools like Nmap, Metasploit, or Burp Suite are only useful once you understand what they're doing under the hood. Someone who only knows how to click buttons in a tool, without understanding networking, operating systems, and the vulnerability the tool is exploiting, will get stuck the moment something doesn't work as expected.

Follow the [roadmap]({{< ref "/roadmap" >}}) on this site. It builds up foundational knowledge (networking, Linux, Windows) before moving into applied security topics like penetration testing and web application security, where specific tools come into play naturally as part of learning the underlying concept.

Once you have the fundamentals down, the best way to learn a tool is to use it on a legal practice target, such as [TryHackMe](https://tryhackme.com) or [HackTheBox](https://hackthebox.com). Read the tool's own documentation, then use it to solve a real practice problem. You'll retain far more from using a tool to accomplish something than from watching a video about it.

> [!CAUTION]
> Never point a hacking tool at a system you don't own or don't have explicit written permission to test. Doing so is illegal, even if you don't cause any damage.
